# Contributing

Thanks for helping improve Unity Mobile Build Doctor.

## Before opening a pull request

- Keep checks read-only and local.
- Give each check a stable code and explain what a developer should verify.
- Avoid collecting secrets or sending project data anywhere.
- Test in the Unity versions you claim to support and include the exact editor version in your notes.
- Update the README when a check or limitation changes.

## Report a bug

Include Unity version, operating system, active build target, reproduction steps, and the exact compiler or runtime message. Remove credentials, signing material, and private project data from logs or screenshots.
